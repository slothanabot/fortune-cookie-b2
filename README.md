A fortune cookie message for a software engineer: the bug was a typo, and it always will be.

> You will fix the bug today. It was a typo. It was always a typo. It will be a typo again tomorrow.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (98 characters, one line, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
